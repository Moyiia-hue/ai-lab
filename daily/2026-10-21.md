### 任务 A：第一次 commit 并连上 GitHub（15 分钟）
- 交付物：GitHub 上的 Moyiia-hue/ai-lab 能看到你的文件
- 对应岗位要求：几乎所有工程岗都要求会用 Git

在 VS Code 终端（项目文件夹里）依次输入：

```
git add README.md ROADMAP.md log.md .gitignore shopping_total.py list_loop_practice.py daily
git commit -m "第一次提交：学习路线和第一个练习"
git remote add origin https://github.com/Moyiia-hue/ai-lab.git

```

- `git add 文件名`：把这些文件放进“待提交”区。这里故意只列学习相关文件，`sea_station/`、`_design_system/` 里有大图片和 .blend 文件，不属于这个仓库，不要提交（之后可以把它们写进 `.gitignore`）。
- `git commit -m "..."`：拍一张快照，引号里写这次改了什么。
- `git remote add origin 地址`：告诉 Git 远程仓库在哪，只需要做一次。
- `git push -u origin main`：上传。第一次会弹出浏览器让你登录 GitHub，这一步要你自己完成。
- 如果 push 报错 `rejected ... fetch first`，说明 GitHub 上已经有文件（比如建仓库时勾了 README），先运行 `git pull origin main --allow-unrelated-histories`，再 push。

### 任务 B：列表和 for 循环热身（30 分钟）
- 交付物：`list_loop_practice.py` 的 5 道小题全部能运行
- 对应岗位要求：Python 基础（美团 Agent 实习等岗位明确写了“熟悉 Python，具备基础数据结构能力”）

打开 `list_loop_practice.py`，按注释一题一题写。先看两个关键语法：

```
fruits = ["苹果", "香蕉"]   # 方括号里用逗号隔开，就是一个列表
for f in fruits:            # 依次把每个元素放进变量 f
    print(f)                # 缩进 4 个空格，表示“这行属于循环”
print("结束")               # 没缩进，循环全部结束后才执行一次
```

最容易错的地方：累加用的 `total = 0` 要写在循环**外面**、循环**之前**，否则每次都会被清零。
